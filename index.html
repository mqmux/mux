这是什么

一套跑在 cmd 里的命令集合

本集合意在为了方便操作 Windows。如果你对命令行脚本、Windows API 感兴趣，本集合很可能会帮到你。

想在上面用 Linux 那种命令？想深入了解句柄、内存、命令行的本质？想学 shell 脚本、各脚本之间的调用、自己写命令？—— 这是一个通过 shell 脚本调用的集合，以 cmd 为基础运行：你既能用 cmd 自带的命令，也能用本集合提供的命令。

功能组成

四个部分，各司其职

外部命令

Compile-bin 目录下是所有的外部命令。

宏命令

宏命令在 Termux.bat 内定义。

轻量工具集

Compile-include 收集了体积较小的 Everything、Tcc、sqlite、spy++、NeatDM 等工具。

发行版附件

FILE 目录下收集了 notepad++ 8.1.0、VIM82、Gcc 3.4.0、CuteHttpFileServer、JiYuTrainer 等。

安装使用

专为小白设计，默认不需要修改任何参数

  1. 下载发行版 exe（上方按钮）。
  2. 右键以管理员身份运行，直接安装即可，集合会自动完成添加。
  3. 安装完成后，在桌面或资源管理器中右键 → Termux，即可在该路径下打开控制台。
  4. 版本有更新时初始页面会提示升级，运行 install -d 即可更新。
注意：本集合不依赖任何运行库，安装一次即可长期使用；安装过程包含注册表操作，因此需要管理员权限。

常见问题

先看这里，多半能解决

杀毒软件报毒怎么办？

报毒属于正常现象。外部命令需要调用系统 API 才能做更多事情，容易被启发式引擎误判；如不放心可直接查看源码。

安装完不知道怎么启动？

右键桌面或资源管理器，点击「Termux 将在此路径下打开控制台」。
